# Newbert web application — F7/F8

Next.js App Router, React and strict TypeScript. Start from the repository root with `npm run dev:web`, or build with `npm run build:web` and serve with `npm run start:web`. Port: **3001**. API must be running on **3100** and PostgreSQL on **54329**. Root scripts retain the existing feasibility prototype separately.

See the [F4 identity record](../../docs/milestones/F4-WEB-AUTH.md), [F5 projects](../../docs/milestones/F5-PROJECTS.md) and [F6 processing](../../docs/milestones/F6-PROCESSING.md). Identity, settings, projects, drafts, version history, queue submission and cancellation are connected. A separate worker is required. Queued discussion, source-backed scripting and storyboard review/approval are connected. Voice generation, video rendering and publishing remain later features. See docs/milestones/F7-F8-PLANNING-STORYBOARD.md. Both public auth origins in the API environment must match the web origin. Never put database or provider secrets in client environment variables.
